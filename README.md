## 🚀 Hướng dẫn Bật GitHub Pages để Xem Trực tuyến (Live Preview)

1. Tạo repository mới trên GitHub (ví dụ: `hr1-chinese-desk`).
2. Đẩy toàn bộ source code lên repo:
   ```bash
   git remote add origin https://github.com/lamduc1123/hr1-chinese-desk.git
   git branch -M main
   git push -u origin main
   ```
3. Trên GitHub, vào **Settings** > **Pages** > Chọn Branch `main` > Nhấn **Save**.
4. Link demo trực tuyến sẽ có dạng:  
   👉 `https://lamduc1123.github.io/hr1-chinese-desk/`
